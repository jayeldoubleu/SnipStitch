# Privacy Policy Last Updated: May 2026 ## Overview SnipStitch is designed to operate completely locally on your computer. We do not collect, store, transmit, sell, or share user data. ## Data Collection SnipStitch does not collect: * Personal information * Usage analytics * Screenshots * Clipboard contents * Account information * Telemetry * Browsing data SnipStitch does not require account creation or cloud connectivity. ## Local File Access SnipStitch only accesses files and screen regions necessary for screenshot capture and image stitching functionality. All processing occurs locally on the user's device. ## Internet Usage SnipStitch does not upload screenshots or user data to external servers. The application may access the internet only when a user manually visits project links such as: * GitHub releases * Documentation pages * Project website links ## Third-Party Components SnipStitch may include or rely on third-party open-source libraries. Applicable licenses and notices are included with release packages where required. ## Security Because SnipStitch operates locally and does not use cloud storage or online accounts, user data exposure risk is minimized. However, users remain responsible for securing their own systems and exported files. ## Children's Privacy SnipStitch is not directed toward children under 13. ## Changes to This Policy This Privacy Policy may be updated periodically as the software evolves. ## Contact Project Website: https://snipstitch.app
